04

版本与复现说明

每个参数实例均有独立目录，参考实现与优化实现共享高层密钥生成、签名和验证流程；差异主要位于参数专用的 Fp/Fp² 算术层。KAT 程序使用提交 API 与确定性随机数生成器，运行后在 build/release/bin/output 下生成对应实例的测试文件。

  • 规范与实现对应关系：源码目录、尺寸常量和 KAT 命名与规范 v1.0 的 8 个参数实例一致。
  • 已知平台限制：多字节值采用小端序；优化实现要求 64 位 x86、BMI2 与 ADX，基准还使用 AVX2 编译选项。
  • 侧信道防护状态：材料未声明完整的常数时间或掩码防护；规范将复杂签名过程的侧信道加固列为实现挑战。
